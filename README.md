# 西陆秋色 / Autumn in Surgea

离线运行的 Web 回合制策略游戏原型。使用 TypeScript、React、Three.js / React Three Fiber、Zustand 和 Vite。所有模式共用一套游戏规则，规则参考 Polytopia 普通部落体系及公开更新说明；代码、界面和程序化几何模型独立实现。

## 安装和运行

需要 Node.js 22.12+（推荐 22 LTS）及 npm。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:5173`。

```bash
npm test        # Vitest 规则测试
npm run build  # TypeScript 检查及生产构建
npm run preview
```

开发入口固定为 `http://127.0.0.1:5173/`，生产预览固定为 `http://127.0.0.1:5174/`。端口占用时报错，不自动改用其他端口，以免本地安装的 PWA 和存档切换到另一个来源。修改源码后，需要重新构建才能更新生产预览。

构建输出在 `dist/`，可以部署到 HTTPS 静态服务器及子目录。游戏规则、AI、模型和音效均在本地完成，无账号、云端 API 或外部美术资源依赖。生产版本已接入 PWA：首次打开并等待“可离线使用”后，可通过“安装游戏”或浏览器安装菜单安装。完整预缓存包含 AI Worker，之后启动和游玩不依赖服务器。开发模式不启用 Service Worker。

```bash
npm run verify:pwa # 检查生产包的离线缓存、Worker、安装清单和图标
npm run bench:ai   # 实际对局与 64×64／11 方压力基准
```

开发网页、本地安装版和 GitHub Pages 的版本与存档边界，以及手动发布步骤见 [部署指南](agent/docs/DEPLOYMENT.md)。安装、离线与更新说明见 [PWA 文档](agent/docs/PWA.md)。

换设备开发时，克隆已提交并推送的仓库，再执行 `npm ci`。继续原有对局需要从旧设备的游戏设置导出 JSON，在新设备导入。测试、详细文档和工具随仓库迁移，本地构建和测试产物可重新生成。更多开发上下文见 [接手指南](agent/docs/HANDOFF.md)。

## 三种模式

| 模式     | 地图                                                                                         | 阵营和城市                                 |
| -------- | -------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 故事模式 | 固定 32×32；中央、西北、北方、南方与东方区域；4 个对手                                       | 使用《世界观.txt》中的五个文明和故事城市名 |
| 自由模式 | 种子决定的噪声地图；可调整陆地、森林、山地、资源、村庄密度和噪声频率；随机、均匀或手动出生点 | 阵营名称可填写，留空随机；城市使用编号     |
| 公平模式 | 旱地、湖泊、大陆、群岛、水世界；使用标准地图预设                                             | 阵营名称可填写，留空随机；城市使用编号     |

自由与公平模式支持 12、16、20、24、32、48、64 格边长，最多 10 个 AI 对手，即 11 方对局。自由模式选择“手动设置”后，在预览图上依次选择各方出生点。出生点必须在内部平原或森林上，并保持至少 3 格距离；不合法配置会在开始前显示原因。

故事模式目前是固定地理的可玩对局，不含剧情章节、任务线或对话。只有故事模式使用世界观名称。现有世界潮汐、政策和自定义文明数值加成都已移除。

## 规则与内容

- 五分支、三个层级、25 项标准科技；研究费用随城市数量增长，哲学提供折扣；支持反向研究相邻科技。
- 星星经济，资源采集，城市人口、等级、容量和按等级选择的升级奖励。
- 标准地块与资源：田野、森林、山脉、浅水、海洋；水果、动物、作物、金属、鱼、海星。
- 战士、骑手、守卫、弓箭手、剑士、投石车、骑士、心灵术士、隐士，以及巨人、匕首和海军体系。
- 由生命比例、攻防和地形计算的确定性战斗；反击、突进、逃脱、连续攻击、老兵、治疗、转化、隐身、渗透及运输。
- 农场、伐木屋、矿场、风车、锯木厂、锻造厂、市场、港口、神庙、桥梁和纪念碑；道路与城市连接。
- 村庄和敌方城市占领、遗迹探索、灯塔、探索迷雾；隐藏单位按隐身规则显示。
- 外交、和平提议、大使馆；统治和 30 回合完美对局。
- 开局预设使用普通部落的初始科技、单位、星星和首都等级，但不绑定原作阵营名称。自由和公平模式可逐方选择，默认随机。
- AI 使用相同 Action 校验和结算接口，在 Web Worker 中执行；动态军队目标和行动预算支持 64×64、10 个对手。简单与普通具有不同的战术、经济和推演能力。
- 地图拖动、缩放、单位移动与攻击反馈、小地图定位、快捷键、自动存档及 JSON 导入导出。

## 操作

1. 开始新游戏，选择模式、地图和对手，点击“开始游戏”。
2. 点击自己的单位，再点击绿色地块移动。点击敌方目标查看预计伤害和反击，再确认攻击。
3. 点击城市，在“城市”页训练单位。点击领土内的资源进行采集和建设。
4. 单位进入村庄或敌城，驻守到自己的下个回合。单位头顶出现旗帜时，点击旗帜打开单位面板，再点“占领”。进入遗迹的单位也要等到下个己方回合才能探索。
5. 点击“科技”打开科技树。悬停科技、建筑或禁用操作可查看作用和限制原因。
6. 城市升级时，点击城上方的双箭头选择奖励。也可以点“选择升级奖励”或按 `Enter` 打开待处理的城市。若有多座城市升级，或人口奖励触发连续升级，逐项选完才能结束回合。
7. 点击“结束回合”，AI 依次行动。统治模式消灭全部对手，完美模式进行 30 回合后结算。

鼠标左键拖动平移，滚轮缩放，小地图可定位。`N` 选择下一单位，`T` 打开科技，`Esc` 取消选择或关闭面板，`Enter` 在奖励选完后结束回合。

## AI 与难度

| 能力 | 简单 | 普通 |
| --- | --- | --- |
| 探索、占领、训练、建设、研究 | 支持，偏重立即收益 | 支持，结合局势、邻接产出和发展收益 |
| 战斗 | 单位逐个选择眼前收益 | 优先集火、解围、高价值目标 |
| 防守 | 基础伤害与反击判断 | 预测可见敌军威胁，驻城、回防和撤退 |
| 行动推演 | 无 | 每方每回合最多 72 次规则调用，比较移动后攻击及生存风险 |
| 军队规模 | 较少、发展较慢 | 随城市容量、探索需求和可见敌情增长 |

两档均无额外资源或规则豁免。隐藏单位不用于战术评分，实际行动必须通过规则层验证。导航支持陆地、港口、运输和登陆；科技选择会考虑资源与海军需求。规则结果、随机扰动和 AI 行动均可复现。

AI 的常规行动预算为 `单位数 × 4 + 城市数 × 7 + 地图边长`，最低 48、最高 1600。预算耗尽后，AI 仍会选完升级奖励并结束回合。领奖和结束回合使用与玩家相同的规则，单独结算。普通难度采用有界启发式，复杂海战、远期外交和超大军团仍有调优空间。实际测试规模及耗时见 [AI 实测记录](agent/docs/AI_BENCHMARK.md)。

Worker 计算期间可以打开设置、拖动和缩放。返回主菜单会中断当前计算，继续游戏会从已保存的回合状态重算；新游戏、读档不会被旧 Worker 结果覆盖。每个 AI 完成后保存检查点，页面关闭后可恢复；线程异常显示“重试 AI 回合”，不会绕过对手或退回主线程进行长计算。

## PWA 更新和存档

主菜单和设置显示离线就绪状态及安装入口。更新下载后显示“更新并重启”，只在用户点击、存档成功且 AI 空闲时重载。其他窗口激活更新不会强制重载正在游玩的窗口。

存档保留 schema 2，与 v0.2 兼容；目前仍使用 localStorage 和 JSON 导入导出。缓存用于程序文件，存档独立保存。安装时会申请浏览器持久存储，但不能阻止用户清除站点数据；重要对局请导出备份。本版没有引入 Tauri、Electron 或后端。

## 规则依据和边界

重点参考官方 Wiki 的科技、单位、战斗、城市、建筑及 2025 年平衡更新，并核对官方商店截图中的布局与操作密度。兵种数值、伤害算例及与原作的核对范围见 [战斗核对](agent/docs/COMBAT_AUDIT.md)。其他规则的来源与版本取舍见 [规则参考](agent/docs/RULES_REFERENCE.md) 和 [已知差异](agent/docs/KNOWN_DIFFERENCES.md)。

“公平模式”是本项目的模式名称，不表示获得了原作的生成器或 AI。地图算法、AI 评分、几何模型与布局是独立实现；不能声称原版源码级或逐像素完全复刻。普通部落的区域资源倍率、原作完整难度体系、特殊部落科技/单位、联网、皮肤和成就体系不在当前版本范围。公开资料有新旧字段冲突，已在规则文档记录取舍；未确认的细节不应视为原版行为证明。

存档使用 schema 2，与先前包含世界潮汐和现代兵种的 schema 1 不兼容。新存档使用独立浏览器键，不覆盖旧版本键。清除网站数据会清除本地存档，需要保留的对局请在设置中导出。

## 目录

```text
src/
  branding.ts           # 中英文显示名称
  assets/fonts/         # 生产版与离线 PWA 共用的本地字体
  game/
    types.ts            # 状态和统一 Action 类型
    data/config.ts      # 科技、兵种、建筑、开局配置
    map/                # 噪声地图与固定故事地图
    rules/engine.ts     # 行动验证、战斗、经济与胜负
    ai/                 # 可见信息、导航、战术、经济、难度与行动预算
  scene/                # 原创 Three.js 模型、地图及动画
  store/                # Zustand、版本化存档与验证
  workers/              # AI Worker、通信与取消/超时处理
  pwa/                  # 安装、离线状态、手动更新
  ui/                   # 菜单、设置、操作栏与科技树
  styles/main.css
  App.tsx
agent/
  docs/                 # 接手指南、规则参考、发布与验收记录
  tests/                # 规则、AI、存档和界面逻辑回归测试
  scripts/              # PWA 产物检查与 AI 基准
AGENTS.md               # 自动化开发代理的入口
public/icons/           # 原创 PWA 安装图标
public/licenses/        # 随应用分发的字体许可证
世界观.txt               # 用户提供的设定，保持原文件
```

规则层不依赖 React 或 Three.js。随机结果使用种子，可用于复现地图和对局问题。大地图基础地块使用实例绘制，地图装饰按视口与缩放裁剪，避免同时绘制全部高细节模型。
