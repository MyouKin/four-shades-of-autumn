# 西陆秋色 / Autumn in Surgea 开发交接

当前代码版本为 **0.3.1**。这是离线单机的轻量回合制 4X 游戏，已经可以开局、发展城市、与 AI 对战、结算胜负、保存与读档。

## 换设备继续开发

1. 在旧设备查看 `git status --short`，用 `git add -A` 暂存源码、运行资产、锁文件、配置和 `agent/`，核对 `git diff --cached --stat` 后提交并推送。首次提交整款应用时，以完整文件清单为准。若继续已有对局，在旧入口的“设置”中导出存档 JSON，单独复制文件。[项目仓库](https://github.com/MyouKin/four-shades-of-autumn)
2. 在新设备克隆或更新仓库到同一提交，使用 Node.js 22.12 或更新版本，运行 `npm ci` 和 `npm run dev`。Vite 开发地址固定为 `http://127.0.0.1:5173/`。如需继续旧对局，在新设备计划使用的游戏入口中打开“设置”，导入存档。
3. 用 `npm test` 检查规则及生命周期回归。用 `npm run build` 生成 `dist/`，随后运行 `npm run verify:pwa` 和 `npm run preview`，生产预览地址固定为 `http://127.0.0.1:5174/`。端口占用时报错，以便保持存档和安装来源稳定。

| 忽略项 | 用途与恢复方法 |
| --- | --- |
| `node_modules/` | 本机依赖，由 `npm ci` 按 `package-lock.json` 安装。 |
| `dist/` | 静态发布产物，由 `npm run build` 重建。 |
| `.DS_Store` | macOS Finder 生成的目录元数据。 |
| `*.tsbuildinfo` | TypeScript 增量构建缓存，下次构建可重建。 |
| `artifacts/` | 本机截图、测试存档、行动样本、旧测试工具的临时打包输出。需要保留原截图或对局时单独复制。 |

`artifacts/` 无需随 Git 上传。以前浏览器验收用的截图与存档样本可按需从旧设备复制。`public/` 下的标识与 PWA 图标是游戏运行资产，应随源代码提交。公共 GitHub 仓库中已提交的 `世界观.txt` 和 `agent/` 可随源码查看，Pages 工作流只上传 `dist/`。

## 已定设计

- 故事模式使用固定 32×32 地图、五个世界观文明和故事城市名称。当前内容是可以征服的固定地图。地理原始资料见 [世界观.txt](../../世界观.txt)，开发约束来自用户的明确要求。
- 自由模式用随机种子和噪声参数生成地图，允许调整地形、资源、聚落密度，以及随机、均匀或手动安排出生点。公平模式用标准地图预设和出生资源保底。自由与公平模式使用独立的阵营命名，名称可填，默认留空并随机生成或分配。两种模式支持最大 64×64、10 个 AI 对手。
- 三种模式共用同一规则引擎。优先参考 Polytopia 普通部落公开规则，保存其轻量节奏和可预判的科技、战斗、地块、建筑语义。程序化几何模型、界面、地图和代码独立制作。现有 25 项科技、星星经济、城建、升级、海军、迷雾、外交与两类胜利条件均可游玩。官方资料冲突、各处实现取舍和公平模式生成边界见 [规则依据](RULES_REFERENCE.md) 与 [已知差异](KNOWN_DIFFERENCES.md)。
- 用户保留世界观文案创作。菜单和操作提示采用直接表述，减少细小的辅助文字。世界潮汐、政策和自定义文明数值加成已从当前规则移除。改动优先满足可玩性、规则完整性和操作体验。
- v0.3.1 使用墨青、象牙白、旧金、绿与赭红，放大界面与地图文字，在桌面和窄屏保留主要操作入口。移动沿规则层合法路径插值，攻击、受击、训练、建设和城市变化提供反馈。AI 整回合快照缺少中间轨迹时，在可见终点显示入场。系统偏好和游戏“减少动画”设置均可生效。详见 [界面配色与动效](VISUAL_STYLE.md)。
- 己方城市有升级奖励时，城上方显示双箭头，结束回合入口与 `Enter` 会打开待领奖城市。多座城市同时升级时可以逐城处理，每座按升级顺序选择。领取人口触发的新等级也必须在本回合选完。AI 通过同一规则领取，常规行动预算耗尽后仍会结清奖励。存档继续使用 schema 2，保留待选等级队列。
- 单位可以实际占领时，模型上方显示旗帜。点击只打开单位面板，再点“占领”执行。棋盘提示限定在己方回合的可见地块。对局界面已移除左上角事件日志与信息面板坐标。标题使用源流明体丹版，其他界面与地图标签使用圆度 40 的 Resource Han Rounded。UI 只设 20px 与 14px 两档，详情见 [界面配色与动效](VISUAL_STYLE.md)。
- 对照原作战斗时先查兵种数值表、伤害与反击算例，以及仍需客户端回放验证的情况。[普通部族战斗核对](COMBAT_AUDIT.md)

## 代码定位

| 位置 | 维护要点 |
| --- | --- |
| `src/game/` | `types.ts` 定义状态和 Action，`data/config.ts` 管理配置，`map/` 负责种子与地图，`rules/engine.ts` 负责验证、结算和合法移动路径。规则层可独立测试。 |
| `src/game/ai/` 与 `src/workers/` | AI 经同一 Action 接口行动。普通档结合经济、威胁预测和有限战术推演，简单档偏重眼前收益，两档都受行动预算约束。注意维持迷雾下的知识边界、Worker 的取消与重试能力。 |
| `src/store/` | Zustand 驱动人类与 AI 回合，按动作及 AI 完成点保存，切换对局时取消旧计算。`save.ts` 验证 `autumn-v2` JSON 和状态引用，旧 `autumn-v1` 规则存档不兼容。 |
| `src/scene/` | R3F 地图、程序化模型、裁剪和动画。动画读取前后快照，判定与存档即时生效。大地图的基础地块用实例化渲染，精细模型按视窗加载。 |
| `src/ui/`、`src/styles/` 与 `src/App.tsx` | 开局、HUD、科技面板、设置、输出反馈和输入。改动后检查桌面与窄屏布局，以及棋盘和平移、缩放是否正常。 |
| `src/pwa/` 与 `vite.config.ts` | Workbox 生成生产缓存，包含 AI Worker。安装与更新状态由前端统一管理，点击“更新并重启”时先保存。相对资源路径和 PWA 作用域支持项目子目录。 |
| `agent/docs/` | 设计取舍、规则参考、部署和验收记录。 |
| `agent/tests/` | `npm test` 执行的 Vitest 回归断言。地图提示见 `map-badges.test.ts`，升级、读档和 AI 领奖见 `city-upgrade-turn.test.ts`，战斗核对样例见 `combat-audit.test.ts`。 |
| `agent/scripts/` | 两个独立 npm 命令的脚本。`npm run verify:pwa` 检查构建后的离线资源，`npm run bench:ai` 测量指定对局的 AI 性能。 |

## 离线与发布状态

开发、生产预览和 Pages 共用同一套游戏代码。开发模式使用热更新。安装版获取同一地址的静态构建，首次缓存完成后可离线运行。存档通过 `localStorage` 保存，键为 `four-shades-of-autumn.save.v2`，按协议、主机和端口隔离。不同设备、浏览器资料、`localhost`、`127.0.0.1` 及 Pages 之间通过已导出的 JSON 搬运对局。Pages 安装从 Pages 地址进行。

GitHub Pages 的手动工作流在 `.github/workflows/deploy-pages.yml`，先安装依赖、跑测试、构建、校验缓存，再发布 `dist/`。截至交接，已有本机生产预览和子目录验收，Pages 地址尚未实际发布与验收。明细见 [部署指南](DEPLOYMENT.md) 与 [PWA 运维](PWA.md)。

本轮 16 个测试文件、233 项测试通过，生产构建与离线缓存校验通过。生产版已在 Chrome 实际操作连续领奖、占领和断网读档推进回合。在内置浏览器中实测过 v0.3 更新、旧存档导入、移动、攻击、训练、建设及 64×64／10 AI 回合。停止本地生产服务器后，浏览器重新开页能读档并推进 AI，早一轮另有完整离线对局。系统安装及独立窗口启动由用户确认，其他实机步骤的记录以 [验证记录](VERIFICATION.md) 为准。大地图后期和难度调优可从可复现种子开始，对比 [AI 基准](AI_BENCHMARK.md)。
